在 Windows 上用 v2rayN、在 Android 上用 v2rayNG 连接灵动云，关键是用**通用订阅链接**，而不是 Clash 订阅链接，这条链接需要向客服领取。v2rayN 在“订阅分组”里添加订阅地址并更新，v2rayNG 在“订阅分组设置”里添加并更新；之后测试延迟、选中节点，再开启系统代理（Windows）或 VPN 连接（Android）。下面先讲订阅格式，再分别讲两个客户端的步骤。

v2rayN 和 v2rayNG 是同一位作者维护的开源客户端，分别运行在 Windows 和 Android 上，通常以 Xray 等作为内核，支持 Shadowsocks、VMess、VLESS、Trojan 等多种协议。灵动云节点使用 Shadowsocks（SS）协议，两者都支持。它们的界面以节点列表为主，适合习惯“看着列表选节点”的用户。

## 先分清两种订阅格式

灵动云按客户端提供三种订阅链接：Clash、通用和小火箭，都要通过用户中心工单领取。和本文有关的是前两种：

- **Clash 订阅**：一份完整的 YAML 配置，节点、代理组和分流规则都写在里面，给 Clash Party、Clash Verge Rev、Clash Meta for Android 等 mihomo 内核客户端使用。
- **通用订阅**：通常是经过 Base64 编码的节点列表，解码后每一行是一个以 `ss://` 等开头的节点链接，给 v2rayN、v2rayNG 这类客户端使用。分流规则不在订阅里，而是在客户端的路由设置中配置。

“支持某个协议”和“能导入某种订阅格式”是两回事。把 Clash 订阅填进 v2rayN，或者把通用订阅导入 Clash 客户端，常见的结果是解析失败或节点列表为空。领取时直接告诉客服你用的是 Windows 上的 v2rayN 还是 Android 上的 v2rayNG，拿到的就是通用订阅链接，不必自己分辨。想改用 Clash 系客户端，可以看 [Clash 订阅导入教程](/guides/clash-subscription/)。

## Windows：v2rayN

### 下载与准备

1. 从 v2rayN 项目的 GitHub 发布页下载与系统和处理器架构匹配的压缩包，大多数电脑选 64 位版本。部分版本需要先安装对应的运行环境，以发布页说明为准。
2. 解压到一个固定的文件夹（路径里最好不含中文和空格），再运行其中的 v2rayN 程序。它是免安装软件，以后升级也在这个文件夹里进行。
3. 部分安全软件会误报客户端或内核文件。确认程序来自官方发布页后，再把它加入信任；来历不明的程序不要这样做。
4. 先退出其他代理工具。多个代理软件同时运行，会互相覆盖系统代理设置。

### 添加订阅并选择节点

1. 打开菜单“订阅分组”，进入“订阅分组设置”，点击“添加”。备注填“灵动云”，地址栏粘贴通用订阅链接，确定保存。
2. 回到主界面，在“订阅分组”菜单中执行更新订阅，节点会出现在列表里。
3. 全选节点，用右键菜单里的延迟测试功能测一遍，按延迟列排序，跳过显示超时的节点。
4. 选中一个延迟正常的节点，把它设为活动服务器（双击或按回车即可）。

v2rayN 和 v2rayNG 也能从剪贴板导入单个以 `ss://` 开头的节点链接，但这样导入的节点不会随订阅更新，节点一调整就会失效。使用灵动云时，请始终通过订阅分组添加。

### 系统代理与路由

窗口底部或托盘图标的菜单里可以设置系统代理：选择“自动配置系统代理”，浏览器和大多数应用就会经过 v2rayN 访问网络；选择“清除系统代理”则恢复直连。旁边的路由选项决定分流方式：日常选择绕过中国大陆地址的规则，国内网站直连，也更省流量；只在排查问题时临时切换为全局。各项名称在不同版本中略有差异，以界面为准。

升级 v2rayN 时，先退出程序并备份所在文件夹，再按发布页说明替换为新版本；节点有调整时，回到“订阅分组”菜单重新执行一次更新订阅即可。

## Android：v2rayNG

### 获取与安装

v2rayNG 可以从项目的 GitHub 发布页或 Google Play 获取。应用商店里有名称相近的其他应用，核对开发者和项目链接后再安装。从发布页下载时，安装包按处理器架构区分，近几年的手机大多选 arm64-v8a；拿不准的话，选标注为通用（universal）的安装包。

### 添加订阅并连接

1. 打开左上角菜单，进入“订阅分组设置”，点击右上角的加号。备注填“灵动云”，地址栏粘贴通用订阅链接，保存。
2. 回到主界面，打开右上角的更多菜单，执行“更新订阅”，节点列表随即出现。
3. 在同一个菜单里执行延迟测试，测完后点选一个延迟正常的节点。
4. 点击右下角的连接按钮。第一次连接时，系统会询问是否允许创建 VPN 连接，选择允许。

### 让连接在后台保持稳定

部分手机的省电策略会在后台关闭客户端，导致连接时断时续。可以在系统设置里把 v2rayNG 的电池使用设为“不受限制”，并允许它显示通知。路由设置中选择绕过局域网及中国大陆地址的预设规则，国内应用直连，也能节省套餐流量。

## 连接后怎样验证

连接成功不等于一切正常，建议做三项检查：

1. 打开平时需要访问的网站，确认页面完整加载；
2. 切换一两个节点，对比访问是否稳定；
3. 检查国内常用应用是否仍然正常，按路由规则它们应当直连。

节点有调整时，两个客户端都要重新执行一次更新订阅，旧节点才会被替换。

## 遇到问题时

导入后节点列表为空，先确认填进去的是通用订阅链接而不是 Clash 订阅链接，拿不准就问一下客服；更新订阅失败或节点全部超时，先在用户中心确认套餐有效、流量充足，再把系统时间设为自动同步后重试。还是不行，把上面几步逐项再检查一遍，再到用户中心提交工单。对客户端、订阅、节点这些概念还不熟悉的，可以先读[客户端、订阅链接和节点分别是什么](/guides/network-basics/)。
