在电脑上用 Clash Party 连接灵动云，按五步完成：从项目的 GitHub 发布页或项目网站下载安装；在“订阅管理”里粘贴灵动云的 Clash 订阅并导入；选中这份订阅作为当前配置；在“代理组”里测速选节点；打开系统代理，模式保持“规则”。之后设置好自动更新，节点调整时客户端会自己同步。

Clash Party（也常写作 ClashParty）是一款基于 mihomo 内核的开源图形客户端，前身名为 Mihomo Party。它的界面会随版本更新而变化，下文的按钮名称以常见版本为准，如有出入，请对照当前界面和项目文档。

## Clash Party 有哪些特点

根据项目 README，Clash Party 以 GPL-3.0 协议开源，主要功能包括：

- 内置 mihomo 内核与 Smart 内核；
- 开箱即用，不安装服务模式也能使用 TUN（虚拟网卡）模式；
- 支持大部分常用的 mihomo 配置修改，并提供“覆写”功能；
- 通过 WebDAV 一键备份和恢复配置；
- 深度集成 Sub-Store，用于订阅管理。

因为内核是 mihomo，Clash Party 能否使用某份订阅，取决于订阅是否为 mihomo 兼容的 Clash 格式。灵动云的 Clash 订阅和 Shadowsocks（SS）节点都在支持范围内。

## 第一步：从官方渠道下载安装

安装包只从两个地方获取：项目 GitHub 页面的 Releases 发布页，或项目 README 指向的项目网站 clashparty.org。网盘转存、论坛附件和所谓的“增强版”都无法确认是否被改动过，不要使用。

发布页按操作系统和处理器架构分别提供安装包，下载前先确认自己的设备：

- **Windows**：大多数电脑选 x64 版本；使用 ARM 处理器的设备，选标注 arm64 的版本。
- **macOS**：点左上角苹果菜单中的“关于本机”，显示 Apple M 系列芯片的选 Apple 芯片（arm64）版本，显示 Intel 处理器的选 Intel（x64）版本，选错会无法运行。
- **其他系统**：以发布页当前列出的版本为准。

首次打开时，系统可能提示无法验证开发者，或者拦截运行。确认安装包来自上述官方渠道后，再按系统提示放行；macOS 在“系统设置 → 隐私与安全性”中确认。来源不明的程序，不要这样操作。

## 第二步：准备订阅链接

导入之前做好三项准备：

1. 登录灵动云用户中心，确认套餐有效、剩余流量充足；
2. 领取 Clash 订阅链接：在[帮助中心](https://lingdongyun.sbs/)联系在线客服，或在用户中心提交工单，告诉客服你在 Windows 或 macOS 上用 Clash Party。通用订阅链接和小火箭订阅链接是给 v2rayN、小火箭准备的，不要拿来导入；
3. 检查链接是否完整，前后没有多余的空格，也没有被截断。

## 第三步：导入订阅并设为当前配置

打开 Clash Party，进入侧边栏的“订阅管理”。把订阅链接粘贴到页面顶部的输入框，点击“导入”。稍等片刻，页面会出现一张新的订阅卡片，通常显示名称和更新时间，服务端提供相应信息时，还会显示已用流量和到期日。

点击这张卡片，使它处于选中状态，客户端就会以这份订阅作为当前配置运行。一份订阅对应一份配置；以后导入了其他配置，切换时同样点击对应的卡片。

## 第四步：选节点并打开系统代理

进入“代理组”页面，展开订阅生成的代理组，点击测速图标测试各节点延迟，选一个数值正常的节点。灵动云节点覆盖香港、台湾、日本、新加坡、美国等地区，访问有地区要求的服务时，选对应地区即可。延迟只反映测试那一刻的往返时间，不必非选数字最小的。

然后在侧边栏打开“系统代理”开关，并把模式选为“规则”：国内网站直连，其他访问按规则走代理。打开浏览器访问常用网站，能正常加载就说明已经连通。

## 第五步：设置自动更新

服务端调整节点后，旧配置里的节点可能失效，所以订阅需要定期更新。在订阅卡片的编辑选项里可以设置更新间隔，按界面显示的单位填写，一般设为一天左右即可；需要立刻同步时，点击卡片上的刷新按钮手动更新。

如果某天发现大部分节点超时，先手动更新一次订阅，再判断是否需要进一步排查。

## 常用设置

### 系统代理与 TUN 模式

系统代理能覆盖浏览器和大多数遵循系统设置的应用。少数程序（例如部分命令行工具和游戏客户端）不读取系统代理，这时可以打开“虚拟网卡（TUN）”，由客户端在系统层面接管流量。根据 README，Clash Party 不安装服务模式也能使用 TUN，但首次开启时系统仍可能要求授权。日常只开系统代理就够用，确有需要再开 TUN；也不要与其他代理软件同时运行，以免互相覆盖设置。

### 覆写

“覆写”可以在不改动订阅本身的前提下，对配置追加或修改内容，例如加入几条自己的规则。订阅更新以后，覆写的内容依然生效。这是进阶功能，不熟悉 mihomo 配置语法时不必使用；改动前记下原来的状态，出问题时关闭覆写即可还原。

### WebDAV 备份

如果你用了覆写，或者调整了较多设置，可以在设置中填写自己的 WebDAV 地址，一键备份配置，换电脑或重装系统后再恢复。备份内容里包含订阅链接，只备份到自己信任、设有访问密码的存储空间。

### Sub-Store

Clash Party 集成了 Sub-Store，可以对多份订阅做合并、筛选等处理。只使用灵动云一份订阅时用不到它；如果要用，先弄清订阅数据会被如何处理和保存。

## 保护好订阅链接

订阅链接里带有与账号绑定的令牌，Clash Party 凭它下载和更新配置。不要在截图、录屏或求助帖中露出完整链接，也不要把它粘贴到来历不明的网站。订阅链接泄露后可以重置，旧链接随之失效；重置后向客服领取新的 Clash 订阅链接，在 Clash Party 中删除旧卡片，再导入新链接。

## 遇到问题时

导入时报错、节点列表为空或全部超时，先确认套餐有效、复制的是 Clash 订阅，再手动更新一次；系统时间不准也会导致连接失败，可以把系统时间设为自动同步。仍然解决不了，按帮助中心的[订阅更新失败与节点超时排查步骤](https://lingdongyun.sbs/guides/troubleshooting/#update-failed)逐项检查，或在帮助中心联系在线客服。
