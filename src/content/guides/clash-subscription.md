在 Clash 系客户端里使用灵动云，只需要四步：向客服领取 **Clash 订阅链接**，粘贴到客户端的订阅（配置）页面导入，选中这份配置并打开系统代理，最后测速选择节点。之后让客户端定期更新订阅，节点有调整时就能自动同步。下文按这个顺序展开，并补充代理组、更新间隔和连接验证的做法。

本文的步骤适用于 Clash Verge Rev、Clash Meta for Android 等基于 mihomo 内核的客户端。用 Clash Party 的读者可以直接看 [Clash Party 教程](/guides/clash-party/)，那篇按它的界面逐项讲解；还没决定装哪个客户端，先看[按设备选客户端](/guides/choose-client/)。

## 现在的 Clash 客户端用什么内核

原版 Clash 内核和早年的 Clash for Windows 都已停止维护，现在常见的 Clash 系图形客户端，大多改用 mihomo（原名 Clash Meta）作为内核。mihomo 沿用了 Clash 的 YAML 配置结构，并支持更多协议和功能，所以客户端里看到的节点、代理组和规则，基本都遵循 mihomo 的配置规范。遇到配置字段方面的疑问，优先查阅 mihomo 的官方文档。

这也意味着，几年前下载的旧版客户端最好不要再用：它们不再获得修复，也可能读不懂新版配置里的字段。

## 导入前确认四件事

很多“导入了却用不了”的情况，并不是操作出错，而是前提条件没有满足。动手之前花一分钟逐项确认：

1. **套餐状态**：登录用户中心，确认套餐在有效期内、剩余流量充足。
2. **订阅格式**：要用的是 Clash 订阅链接。灵动云另有通用订阅链接和小火箭订阅链接，分别给 v2rayN、v2rayNG 和小火箭使用，导入 Clash 会解析失败。
3. **客户端版本**：使用仍在维护的正式版，从项目的官方发布页下载与系统、芯片对应的安装包。
4. **协议支持**：灵动云节点使用 Shadowsocks（SS）协议，mihomo 内核原生支持，不需要额外设置。

另外要分清三种链接。**注册入口**用来注册、登录和管理账号，不能导入客户端；**订阅链接**由客服按你的设备和客户端发给你，是专属于你账号的地址，客户端用它获取并更新节点列表；以 `ss://` 开头的**节点链接**只代表单个节点，不会自动更新。导入客户端要用的是订阅链接，它相当于账号凭证，不要公开分享。

## 第一步：向客服领取 Clash 订阅链接

灵动云的 Clash 订阅链接需要通过客服获取。打开[帮助中心](https://lingdongyun.sbs/)的在线客服，或者登录用户中心提交工单，说清你的设备和客户端，比如“Windows 电脑，用 Clash Verge Rev”，客服会把对应的 Clash 订阅链接发给你。复制时可以先粘贴到记事本里看一眼：链接应当完整，前后没有多余的空格或换行。

## 第二步：在客户端导入订阅

以 Clash Verge Rev 为例：打开客户端，进入“订阅”页面，把链接粘贴到顶部的输入框，点击“导入”。客户端会下载配置文件，成功后列表里多出一张订阅卡片，通常显示名称和更新时间；服务端提供相应信息时，还会显示已用流量和到期日。

其他 mihomo 客户端的入口可能叫“配置”或“Profiles”，操作逻辑相同：新建一份来自 URL 的配置，粘贴链接，保存。

### Android 上的 Clash Meta for Android

打开 Clash Meta for Android，进入“配置”，新建一份配置并选择从 URL 导入，填写名称（例如“灵动云”）和订阅链接，按需设置自动更新间隔后保存。回到配置列表选中它，再回到首页点击启动；系统询问是否允许创建 VPN 连接时，选择允许。

## 第三步：启用配置并开启代理

在订阅列表中点击刚导入的卡片，让它成为当前使用的配置。然后打开“系统代理”开关，浏览器和大多数应用就会经过客户端访问网络。

部分客户端还提供“虚拟网卡（TUN）模式”，它能接管不遵循系统代理的应用，但通常需要管理员权限或额外授权。第一次使用建议只开系统代理，确认一切正常后再按需开启 TUN。

代理模式方面，“规则”模式按配置里的规则分流，国内网站直连、其他访问按需走代理，是日常推荐的选项；“全局”模式让所有访问都经过节点，一般只在排查问题时临时使用。

## 第四步：测速并选择节点

进入“代理”页面，可以看到配置生成的若干代理组。点击分组旁的测速按钮测试延迟，选择显示正常数值的节点，显示超时的节点暂时跳过即可。灵动云节点覆盖香港、台湾、日本、新加坡、美国等地区，访问有地区要求的服务时，选择对应地区的节点。

延迟只代表测试那一刻数据往返一次的时间，不等于下载速度，不必非选数字最小的那个。

## 代理组怎么用

mihomo 支持几种常见的代理组类型，订阅生成的分组通常就是它们的组合：

- **select**：手动选择，适合想自己决定用哪个节点的情况；
- **url-test**：定期测试延迟并自动选择，`tolerance` 用来设置切换容差，避免节点频繁跳动；
- **fallback**：当前节点不可用时，按列表顺序切换到下一个可用节点；
- **load-balance**：在多个节点之间分配连接。

日常浏览可以交给自动选择的分组；视频会议、远程桌面这类要求连续性的场景，建议手动固定一个表现稳定的节点，减少中途切换。

## 订阅更新：手动更新与自动更新

服务端会调整节点地址、增减节点或更新规则，所以订阅需要定期更新。发现节点大面积失效时，第一件事就是在订阅卡片上手动更新一次。

更省事的做法是设置自动更新：在订阅卡片的编辑选项里填写更新间隔（单位以客户端显示为准），一般设为一天左右即可。如果你自己维护配置文件，通过订阅获取的节点属于 mihomo 的“代理集合”（proxy-providers），常用字段如下：

| 字段 | 作用 |
|---|---|
| `type` | 集合类型，通过链接获取时为 `http` |
| `url` | 订阅地址 |
| `interval` | 自动更新间隔，单位为秒 |
| `health-check` | 健康检查，可设置检测地址、间隔与超时 |
| `filter` | 按关键词或正则只保留部分节点 |

## 怎样确认已经连接正常

1. 打开平时需要访问的网站，确认页面完整加载；
2. 打开几个国内常用网站或应用，规则模式下它们应当直连，速度不受影响；
3. 在客户端的“连接”或“日志”页面，查看访问分别命中了哪个代理组。

日常维护也很简单：定期更新订阅；客户端保持更新，但升级前看一眼版本说明；如果改过配置，先备份再更新。

## 遇到问题时

节点列表为空、全部超时或提示格式错误时，先在用户中心确认套餐有效、流量充足，再手动更新一次订阅，并确认导入的是 Clash 订阅链接，而不是给 v2rayN 或小火箭用的另外两种，拿不准就问一下在线客服。仍未解决的，到帮助中心的[连不上怎么办](https://lingdongyun.sbs/guides/troubleshooting/)页面逐项检查；截图求助时，记得把订阅链接打码。
