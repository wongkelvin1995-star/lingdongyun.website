Clash 是一类以“配置文件 + 规则分流”为核心的代理客户端的统称。原版 Clash 内核与早期的 Clash for Windows 已停止维护，现在常见的是基于 mihomo（Clash Meta）内核的图形客户端，例如 Clash Verge Rev、Clash Party 等。客户端名称和版本更新很快，下载前请到对应项目的官方发布页确认当前名称、支持的系统与最新正式版本。

本文以 Clash 系客户端为例，讲清楚从购买套餐到首次连接的完整流程。如果你还不太清楚“客户端”“订阅”“节点”分别是什么，建议先读[科学上网入门](/guides/network-basics/)。

## 导入前先确认四件事

很多导入失败并不是操作错误，而是前提条件没满足。开始之前，请逐项确认：

1. **操作系统与芯片**：Windows、macOS（Apple 芯片或 Intel 芯片）、Linux 对应的安装包不同，选错会无法运行。
2. **客户端版本**：使用正式版，并尽量保持最新。旧版本可能不支持较新的协议或配置字段。
3. **订阅格式**：Clash 系客户端读取的是 Clash 格式（YAML）的订阅。用户中心通常会针对不同客户端提供不同的订阅入口，请选择标注为 Clash 的那一项。
4. **协议支持**：灵动云使用 Shadowsocks（SS）协议，mihomo 内核支持 SS；如果你使用的是其他内核的客户端，请先确认其协议支持范围。

## 分清三种链接

新手最常混淆的是这三种链接：

- **注册入口**：灵动云官方入口地址，用来注册、登录、购买和管理账号。它不能导入客户端。
- **订阅链接**：在用户中心登录后才能看到，是一串专属于你账号的地址。客户端通过它获取节点列表，并可以定期更新。
- **节点链接**：以 `ss://` 等前缀开头，只代表单个节点，不会自动更新。

导入客户端时要用的是**订阅链接**。它相当于账号凭证，不要截图发到群里或公开论坛。

## 从购买到导入的步骤

**第一步，购买并确认套餐生效。** 通过官方入口登录用户中心，选择套餐并付款，然后在套餐详情中确认状态为有效、剩余流量正常。

**第二步，复制 Clash 订阅链接。** 在用户中心的订阅区域找到适用于 Clash 的订阅入口并复制。不同面板的按钮名称与位置可能不同，以你看到的页面为准。

**第三步，在客户端中添加订阅。** 打开客户端，进入“订阅”或“配置”页面，粘贴链接并保存。客户端会下载配置文件，成功后会显示配置名称、更新时间或剩余流量等信息。

**第四步，启用配置并开启代理。** 选中刚导入的配置，打开系统代理开关。部分客户端还提供“虚拟网卡（TUN）模式”，它能接管更多应用的流量，但通常需要管理员权限，初次使用可以先不开启。

## 选择节点并验证连接

导入成功后，在“代理”页面可以看到节点分组。点击测速按钮测试延迟，选择有正常延迟数值的节点；显示超时的节点暂时跳过即可。

模式方面，“规则模式”会根据配置中的规则决定哪些访问走代理、哪些直连，是日常使用的推荐选项；“全局模式”让所有流量都经过代理，一般只在排查问题时临时使用。

最后打开你平时需要访问的网站或应用，确认能正常加载。之后记得定期点击“更新订阅”，或在客户端里设置自动更新间隔，以便获取最新的节点列表。

## 导入失败时先看这里

如果提示下载失败或解析错误，按以下顺序检查：套餐是否到期、流量是否用尽；复制的是否是完整的 Clash 订阅链接；客户端版本是否过旧；当前网络能否正常访问订阅地址。更完整的检查清单见[订阅更新失败与节点超时排查](/guides/troubleshooting/)。

Windows 与 Android 用户如果想了解 v2rayN、v2rayNG 等其他客户端，可以阅读 [Windows 与 Android 客户端选择指南](/guides/windows-android-clients/)；获取客户端的入口与平台说明，见首页的[客户端与快速开始](/#clients)。
