客户端是装在你设备上的软件；订阅链接是一条专属地址，让客户端拿到可用的节点清单；节点则是实际帮你转发数据的服务器。三者缺一不可：只有客户端没有订阅，就没有节点可用；只有订阅链接没有客户端，链接本身什么也做不了。

“梯子”“机场”这类口语说法，指的都是这种代理订阅服务。不管叫法如何，弄懂下面几个概念，后面看任何一篇设备教程都会顺畅很多。本文只讲概念，不涉及具体按钮。

## 一张表看懂常见名词

| 名词 | 是什么 | 在灵动云里对应什么 |
|---|---|---|
| 服务（俗称“机场”） | 提供节点的服务商 | 灵动云本身 |
| 节点 | 部署在某个地区的代理服务器 | 覆盖香港、台湾、日本、新加坡、美国等地区 |
| 协议 | 客户端与节点之间的通信方式 | Shadowsocks（SS） |
| 订阅链接 | 带令牌的专属地址，客户端用它获取并更新节点 | 分 Clash、通用、小火箭三种，向客服领取 |
| 客户端 | 安装在设备上的软件 | Clash Party、小火箭、v2rayN 等 |
| 内核 | 客户端里真正负责连接的程序 | mihomo、Xray 等 |
| 规则 | 决定哪些访问走代理、哪些直连 | 写在 Clash 订阅里，或在客户端中设置 |

打个比方：服务像一家航空公司，节点是它开通的航线，订阅链接是你的登机凭证，客户端则是帮你办理登机、选择航线的工具。

## 客户端：设备上的“播放器”

客户端负责三件事：读取配置，与节点建立加密连接，再按规则决定每一次访问是走代理还是直连。它本身一般不带可用的节点。下载了客户端，只相当于有了播放器，还需要片源。

客户端的界面和内核是两回事。Clash Party、Clash Verge Rev 用的是 mihomo（原名 Clash Meta）内核，v2rayN、v2rayNG 通常用 Xray 等内核，小火箭则是独立开发的 iOS 应用。内核决定了客户端能读哪种订阅格式、支持哪些协议，这也是选客户端时要先看订阅格式的原因。

## 订阅链接：一份会更新的节点清单

订阅链接是服务为你的账号生成的专属地址。客户端访问它，就能拿到当前可用的节点列表；节点有调整时，只要“更新订阅”就能同步，不必手动逐个添加。

灵动云的订阅链接有三种：Clash 订阅是一份完整配置，节点、代理组和规则都在里面；通用订阅一般是 Base64 编码的节点列表，规则由客户端自己设置；小火箭订阅则专供 iPhone、iPad 上的小火箭。客户端读哪种格式，就用哪一条；联系客服时说明设备和客户端，客服会发来对应的那一种。

订阅链接里带有与账号绑定的令牌，拿到链接的人就能使用你的套餐流量。把它当作密码对待：不发到群里，不贴进来历不明的网站，截图时记得打码。

## 节点：实际转发数据的服务器

节点是分布在不同地区的服务器。连接某个节点后，你的请求会先加密发送到这个节点，再由它访问目标网站，把结果传回给你。灵动云的节点覆盖香港、台湾、日本、新加坡、美国等地区，走 IEPL / IPLC 优化线路。

客户端里显示的延迟，是测试那一刻数据往返一次的时间，可以用来排除不可用的节点，但不等于下载速度。实际使用时，选一个延迟稳定、访问顺畅的节点长期使用，比频繁追逐最低的数字更省心。

## 一次访问是怎样完成的

把上面几个概念串起来，一次典型的访问是这样的：

1. 你在用户中心开通套餐，再向客服领取与客户端对应的订阅链接；
2. 把订阅链接导入客户端，客户端下载节点列表和配置；
3. 你打开一个网站，客户端按规则判断这次访问是否需要走代理；
4. 需要代理的请求被加密发送到你选定的节点，由节点访问目标网站；不需要代理的，直接连接。

在 mihomo 内核的配置里，从订阅获取的节点叫作“代理集合”，可以按设定的间隔自动更新；节点又会被组织成“代理组”，比如手动选择组、按延迟自动选择组和故障时自动切换组。具体怎么用，见 [Clash 订阅导入教程](/guides/clash-subscription/)。

## 规则、全局、直连三种模式

大多数客户端都提供三种模式：

- **规则模式**：按规则分流，国内网站直连，其他访问按需走代理。日常推荐，也更省套餐流量。小火箭里对应“配置”。
- **全局模式**：所有访问都走代理，适合临时判断问题是否出在规则上。
- **直连模式**：所有访问都不走代理，相当于暂时关闭。

## “全球加速”能做什么，不能保证什么

代理服务让你的访问经由网络条件较好的路径到达目的地，从而改善跨境访问的连通性和稳定性。但它无法保证在任何地点、任何时间都一样快，影响因素包括：

- **你所在的网络**：不同城市、不同宽带运营商到同一节点的线路质量不同；
- **时段**：晚间用网高峰时，跨境线路普遍更拥挤；
- **节点负载**：同一时间使用同一节点的人越多，每个人可用的带宽就越少；
- **目标网站**：网站自身服务器的位置和状态同样影响速度，部分网站和应用还会按地区调整可用内容。

所以，看到“任何时间都满速”之类的说法，以自己在常用时段的实际体验为准。也请在所在地法律法规允许的范围内使用网络服务。
